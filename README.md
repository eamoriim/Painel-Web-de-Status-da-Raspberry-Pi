Painel Web de Status da Raspberry Pi

Aplicação web desenvolvida para monitorar o estado de uma Raspberry Pi através de um navegador. O sistema coleta informações reais do sistema operacional e apresenta os dados em um painel simples e organizado.

📌 Sobre o projeto

A proposta do projeto é facilitar o acompanhamento de uma Raspberry Pi utilizada para executar serviços em uma rede local.

Atualmente, para verificar informações como utilização do processador, memória ou temperatura, é necessário acessar a Raspberry Pi por SSH e executar comandos no terminal.

O projeto busca simplificar esse processo disponibilizando uma página web que pode ser acessada por qualquer dispositivo conectado à mesma rede.
